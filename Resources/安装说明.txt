RecordAI 0.15.2 · Apple Silicon / macOS 14+

安装：双击 PKG 按向导安装，或打开 DMG 将 App 拖入 Applications。
本地测试签名，尚未进行 Apple 公证。

本版语音模型独立下载：
• Paraformer INT8：录音过程中持续显示中英实时转写。
• Silero VAD：检测语音，静音不会交给识别模型。
• Qwen3-ASR 1.7B 8bit：会议录音在停止后定稿；持续录音在片段关闭后定稿。
首次录音前点击“下载模型”，下载校验完成后可离线使用。权重保存在本机数据目录，升级不重复下载。无需 API Key、Python 或 Homebrew。
本版聚焦录音和转录；历史摘要、笔记和问答保留只读，不再提供生成入口。

麦克风或系统声音首次使用时，按 macOS 提示授权。
系统声音采集使用 ScreenCaptureKit，不保存屏幕图像。
线上会议建议佩戴耳机，避免扬声器被麦克风重复拾取；尚无声学回声消除。

已有会议点击“继续录音”，新音频与新文字保存在同一会议里，旧文字和笔记保留。
“更多”菜单可新建会议、重新转录、导出或移到废纸篓。
会议录音的实时文字未定稿，停止后根据完整音频生成定稿；持续录音在片段关闭后边录边生成定稿和发言人标签。
正文的发言人分段使用逐词对齐；“原始字幕”仍保留语音片段起止时间。

音频及文字保存在 ~/Library/Application Support/CoHearTranscribe/。
转写和发言人分析均在本机处理；仅当你主动确认同步时发送会议文字到所选工作区。
卸载不删除会议。旧版转录保留；若希望按新模型重新识别，可在更多菜单选择重新转录。

第三方引擎与模型许可证位于 App 内 Contents/Resources/Licenses/。
AI识别可能出现遗漏或错误，请结合原始录音核对，不保证消除所有幻觉。

0.9.0：会后自动用Sortformer区分发言人，用Qwen对齐模型对应到文字。最多4位/独立录音；续录标签独立，可手动合并。
转写统一时间线，活动句与已确认句分开；会议录音停止后定稿，持续录音逐片段定稿和分人。支持发言人改名、合并/恢复独立标签、段落纠错与点击时间回放。
发言人分段不保证真实身份或全部正确，多人抢话/噪声时请结合原录音核对。

0.9.0：录音库、转录画布与交付入口。支持TXT/Markdown/JSON/原始SRT及全部音频导出，个人平台同步前预览；本机Agent可读AgentData目录，或使用App内Contents/MacOS/recordai的只读CLI/MCP。详细接入说明可从设置复制。

0.9.1：退出时可选择保存录音并退出，或取消转录并退出。音频保存失败不会自动退出。

0.10.0：真实录音电平声波、后台峰值缓存与波形定位；输入配置变化/无帧时暂停保护，原轨可从“恢复中断录音”恢复保存，重复恢复不追加副本；可仅修改一段的发言人并撤销。

0.10.1：点击定稿正文或时间定位本段，播放到段尾自动暂停。播放器按钮或拖动波形切回连续播放。

0.15.1：默认实时转录，保留后台实时和仅录音后转录选项。窗口隐藏/最小化只减少界面更新，不停止实时识别；录音可从菜单栏暂停或停止。关闭录音窗口继续运行，退出应用仍需正常保存/取消任务。


RecordAI 0.15.1：本机 Agent 可通过 Contents/MacOS/recordai control ACTION --root PATH 控制录音，也可使用 MCP 的 control_recording。控制命令异步执行，结果写入 AgentData/Control/results。

0.15.1：安装包移除全部语音模型权重。首次使用一键下载，显示进度，可取消/重试；逐文件大小和 SHA256 校验，完成后才启用。已验证文件缓存保留，未完成的当前文件重试时重新下载。

0.15.1：模型下载支持中国 ModelScope 和海外 Hugging Face／Silero 官方源。按系统地区优先，失败自动切换；两源使用相同的大小与 SHA256，取消不会触发备用下载。
