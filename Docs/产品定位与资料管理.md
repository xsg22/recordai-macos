# 产品方向：录音资料库与 Agent 接入

2026-11-02 当前范围：桌面端负责录制、导入、保存、回听、转录和管理音频；外部 Agent 按需分析和处理转录结果。根据用户最新反馈，撤回开发中的标签与时间点功能，仅保留录音、转录及一层分组。本次交付版本为 0.16.2 功能验证版，候选包实测见[验证记录](validation/release-0.16.2/README.md)。

## 主流程和界面

录制或导入 → 原音可靠保存 → 转录与修订 → 搜索、分组整理 → 交给 Agent。

主阅读页直接展示正文，不再设置转写/时间点切换页签。转录提供完整正文的阅读、纠错与按时间回听，采用时间、发言人和正文同一行的紧凑布局，长句在正文列换行。重复的转录时间线已合并回转写，数字头像移除，原有播放、编辑和发言人菜单保留。

移除内置笔记、摘要、问答、Live Q&A、行动项的全部界面入口和应用内调用链，包括原来折叠区域中通向旧工作台的入口。右侧只展示录音分组，设置不再提供辅助总结模型管理。既有笔记、总结、引用和数据继续兼容保存，不自动清理模型文件。查询和分析交给外部 Agent，不会顺带启动录音。

侧栏仅保留一行分组选择与管理入口；批量整理入口合并进录音列表标题行，进入选择模式后才显示批量操作条。设置和执行追踪合并成底部一行，让录音列表获得更多高度。

## 分组

每条录音属于一个主分组，默认未分组。支持创建、重命名、移除、单条和批量移动；展示名称可修改，groupID 保持稳定。分组移动只改元数据，不移动或复制音频、不改变 recordingID。移除分组后录音回到未分组，回收站中的记录恢复时也不会复活已移除分组。

名称为 1–40 字，不允许空白、换行或重名。保存失败保留输入，批量写入失败报告实际已成功数量，不显示未保存结果。

标签的编辑、筛选、搜索、批量操作、数据模型和 Agent 参数均已移除。旧开发数据中多余字段可被兼容读取并忽略，之后保存不再编码；旧公开快照重新发布时清除已退休字段，并通知缓存的 Agent 刷新。旧音频、正文和分组不受影响。

## 暂缓的功能

按用户最新决定，标签和手动时间点均暂不提供，后续有明确需求再添加。时间点的页签、侧栏、段落菜单、表单、持久化字段、搜索和 Agent 返回字段已移除。原文自带的时间戳、逐段播放和自动段尾暂停仍保留，它们属于转录的基本回听能力。

旧开发版数据中的退休字段会被兼容读取并忽略，后续保存不再编码。公开快照重发时清理相应字段并发布元数据变更，不改动音频、转录正文、段落 ID 或分组。原个人资料库不进行批量改写。

## Agent 契约

`recordai list --query TEXT --group UUID`，`--ungrouped` 查询未分组。MCP `list_recordings` 对应可选的 `query`、`groupId`、`ungrouped`。查询匹配录音标题、正文、分组名。已移除的标签参数会报错，避免误返回未筛选的全部资料。

`read.organization` 包含 group 和独立 revision。整理变化发布 metadata 事件及 metadataRevision，不改变转录 revision/contentDigest。正文段落 ID、时间戳、修订号及原有读取方式保留。事件写入中断后重新发布可补齐缺失事件。

分类目录独立原子写入 organization.json。索引损坏会报告错误，不将其误判为全部资料已删除并清空公开快照。Agent 接口保持只读整理信息，录音控制仍须明确请求。

## 转录碎段

新识别在发言人对齐后合并紧邻的短碎段，Python 引擎和 Swift 接收端均处理。正文、标点、换行及时间范围保留；混合归属标为待核对，不伪称重叠发言。静音、句末、音轨边界、人工归属及完整短答不强行合并。

旧转录仅在阅读层分组，可以展开原始段落编辑或回听，也可以播放完整合并片段。历史来源 ID 保留，不自动批量改写个人库。真实长录音曾从 259 个原始段落整理为 176 个阅读段，单字符段从 49 个降至 2 个；这是碎段改善，不能等同于识别准确率提高。

## 验证及边界

重复验证：`zsh Scripts/test-library-management.zsh [真实 meeting.json 的只读路径]`。默认使用隔离合成数据；真实路径只在内存中检查阅读分组，不写回个人库。

覆盖旧数据兼容、分组持久化/筛选/批量移动、移除与回收站恢复、真实播放器、快照独立版本与故障恢复，以及 CLI/MCP 查询和退休参数拒绝。原生界面在隔离预览中另行核对，私人录音和截图保存在仓库外。

尚未实现原始录制时间与导入时间分离，也未提供人工标准稿支持的识别准确率。这些资料管理功能从 0.16.2 起提供，旧安装版本不具备。先前含标签、时间点和时间线的验收日志保留为历史记录，不代表当前产品范围。
