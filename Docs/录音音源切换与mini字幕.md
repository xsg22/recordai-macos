# 录音中切换音源与 mini 流式字幕

2026-11-03，按已确认的紧凑双行交互稿实现。

## 行为

- 主录音页与 mini 共享麦克风、系统声音两个开关；只影响本次录音，不修改设置里的默认音源。
- 允许两个音源同时关闭：静音录制、计时继续、已有原音和文字保留。暂停仍会停止计时。
- 切换时仅对应按钮显示 loading，不增加常驻提示行。开启新音源失败时保留原音源，并在发起操作的按钮处提示原因和重试。
- 新源启动完成后才提交切换；停止录音会使尚未完成的切换失效。切换间隙和静音不压缩时间；按采样时间裁切迟到的回调，防止旧音频混入已关闭区间。
- 录音目录保留 `sources.json` 切换记录。原始双轨各自保存，最终混音保留录制总时长。全程主动静音也可生成真实静音文件；硬件没有提供音频且没有主动静音时仍报错。
- mini 为 525×76pt，字幕区 180pt：上一条确认文字和当前流式草稿各一行，长句从尾部显示最新内容。字幕按钮在原位置切换声波；不会增加下方字幕层。
- 可见 mini 的草稿及时呈现，不受隐藏主窗口两秒呈现节流影响。ASR 是否运行仍遵循会话模式；“仅录音”不会因为打开字幕而启动模型。
- 置顶、模式选择和收起到菜单栏保留在 mini 的右键菜单中。

## 录音时浏览其他记录

录音会话 ID 与资料库选择分开。当前录音详情只显示完整录音控件，不再叠加 mini；浏览历史录音、搜索或切换筛选时，录制、计时、音源状态和实时草稿仍属于原会话。历史页底部显示同一会话的 mini，并可通过侧栏或 mini 的“返回正在录音”返回、清除筛选。

历史正文、历史实时预览和回放使用所查看的记录，可播放全文、单句和拖动进度；不播放正在写入的原音。实时提交和持续切片只写入录音 ID 对应的记录。浏览历史页时停止录音，保存和自动转录仍指向原会话，保留浏览位置。批量整理、删除、新建录音和重新转录等写操作继续受任务状态约束。

`RecordingBrowsingSmoke` 使用真实静音会话和音量为零的播放器，验证切换/返回、实时草稿隔离、单句与完整回放、停止后的音频归属和历史文件逐字节不变。最终日志为 `.build/browse-recording-regression-final.log`，界面契约日志为 `.build/browse-recording-contracts.log`。原生隔离预览实际点击确认：录音页无重复 mini、历史页显示 mini、mini 返回按钮恢复录音页。

本地工作分支为 `codex/readme-contact`，未提交或推送。本次候选输出到 `.build/recording-browser-candidate/RecordAI.app`，重新编译并通过签名检查；源码/二进制摘要保存在同目录 `build-manifest.json`。未覆盖或重启正在录音的旧候选，当前录音不受影响；停止录音并退出后再切换到新候选。

- 两个开关全关、跨切换边界的迟到帧裁切、两轨重新开启与中间静音。
- 实时混音和持续切片的静音时间推进、最终混音时长、切换记录落盘。
