## 发现并修复的主分支问题

`MacLibrarySyncAdapter.values` 在录音/转录期间会把快照中的未知时长从 `nil` 改为 `0`，导致未改变的定稿被识别为新变更。现在保留未知值；已有零时长或已知时长的行为不变。`RecordingDomainSmoke` 保留原有完整快照相等断言并已通过。

离线冲突测试中的临时活动录音，仅用于检查临时字幕排除。现在在跨进程重启阶段前清理该合成条目，避免正确的录音恢复与全库自动同步行为使待同步条目数量增加；原有离线队列、冲突选择、分组改名和账号隔离断言均保留。
