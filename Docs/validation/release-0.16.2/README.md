# RecordAI 0.16.2 发布验证

本版将桌面端收敛为录音、导入、转录、逐段回听、人工校正和分组管理。内置笔记、摘要、问答、Live Q&A、行动项及辅助模型的操作入口和 AppState 调用链已移除；旧历史内容兼容保存。外部 Agent 的 Skill、CLI/MCP 和录音控制能力保留，新增分组查询和独立元数据版本。

正式候选包为 0.16.2 / build 37，应用与资源摘要为 `90e98c7ca220fcc1e7cb441125ee828fa11cb20fa534f99d4a4118ed1d35666e`。验证使用候选包原始二进制与临时隔离 Home；模型复用本机已下载权重，不改写个人录音库。

通过系统面板导入 31.296 秒双人合成音频，实际点击“开始转录”，包内新构建的引擎耗时约 9.726 秒，保存 4 段、2 位发言人，首次有效转录后展示 Agent 引导。源 WAV 与受管副本哈希相同。点击第二段，观察到 9.063 秒的播放进度，并在 13.85 秒段尾自动暂停。

通过实际段落编辑窗口将末段“测试组完成首页交付”校正为“设计组完成首页交付”。比较编辑前后，段落 ID、时间、发言人、音频和原始字幕保持不变。通过系统保存面板导出原始/校正 Markdown 和原始 SRT，核对正文、发言人、时间标记及原始字幕。附件仅含合成演示内容，不提交私人录音。

实际创建三个演示分组，将录音归入“产品讨论”，并修改演示标题。检查窄窗口的整理弹窗、宽窗口右侧、更多菜单、导出页和模型设置；没有通向旧工作台的入口。README 新图直接来自候选客户端，详见 `ui-validation.json`。CLI 与 MCP setup 一致，均可查询本次校正后的转录和分组，运行状态未录音。

`Scripts/release.zsh --candidate` 完成 14 组录音/资料回归、8 组既有契约、CLI/MCP/Skill 集成、5 组资料管理回归、碎段 Python 契约及 9 项报告测试；完整日志见 `build-and-verification.log`。模型/助手的独立旧工具类契约仍执行，不代表产品入口存在。DMG 只读挂载、PKG 展开，实际核对签名、arm64、内置 Python 3.12、语音引擎、Skill/CLI、包内二进制与 SHA-256，均通过。

`functional-release-binding.json` 指向本目录，门禁核对当前应用与资源、运行时输入、真实导入/分人/回放/校正/导出和候选包证据。本次允许功能验证 prerelease，未将历史全套设计稿验收标为通过。

未验范围：真实硬件录音与首次系统授权、外部 OAuth 和远端文档写入、各品牌 Agent 的全部真实加载环境，以及完整设计稿逐页视觉还原。合成音频有一处已知识别错误；碎段减少不等于识别准确率提高。升级保留原音、转录和模型；可用 0.16.1 安装包回退。
