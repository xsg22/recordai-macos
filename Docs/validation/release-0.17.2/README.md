# TalkTuck 0.17.2（44）发布验证

本版在 main 的 953ae7b 基线上集成 Mac 客户端变更，保留录音设备恢复和重复窗口修复。应用、语音引擎与两个安装包的哈希见 [result.json](result.json)，应用输入以 sourceDigest 绑定。

- 综合回归通过：录音状态、暂停与恢复、音源切换、mini、后台转录、资料管理、播放、分组、校正、导出、Agent CLI/MCP、中英文和授权契约。
- DMG/PKG 的 SHA-256、签名完整性、arm64、内置 Python 3.12、包内引擎和实际提取内容通过校验；新 PNG 图标与源码资源相同。
- 正式客户端实际导入 26 秒合成中文语音，完成包内模型识别与发言人分析；实际分段回放在段尾自动暂停。
- 原生段落编辑器将“Talk Talk”校正为“TalkTuck”、“代办”改为“待办”；段落 ID、时间戳、发言人、原始字幕及音频哈希不变。
- 实际创建工作、学习分组并将录音归入工作；包内 CLI/MCP 查询到最新正文和分组，Markdown 导出包含校正后的文字。
- 账号与热词的隔离回环服务测试通过，覆盖离线修改、冲突重试、恢复与账号隔离；不等于真实 iPhone 或生产账号联测。

## 截图来源与敏感信息

README 四张新图均来自 0.17.2（44）正式二进制，不使用设计稿或预览入口。录音资料为系统语音合成；资料库图含上述人工校正，Agent 引导图保留最初识别结果。未使用个人录音。

CFFIXED_USER_HOME 只隔离录音与偏好目录，不隔离系统钥匙串。复核时排除了一张出现掩码账号信息的待用截图；公开图片只保留不含账号信息的页面。公开变更在 push 前检查真实凭据、个人路径、手机号、设备标识、内网地址、数据文件及图片；合成测试身份和回环地址单独核对。安全检查结果见 [security-review.json](security-review.json)。

## 范围

本版为用户批准的主功能验证预发布，不声称完整设计册逐页验收完成。未新增真实硬件录音、短信登录、手机/Watch 双向同步或第三方真实授权测试。应用使用本地 ad-hoc 签名，PKG 未签名，尚未 Apple 公证。
