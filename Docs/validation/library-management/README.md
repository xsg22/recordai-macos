# 资料管理开发版验收

## 当前范围：录音、转录、分组

本轮进一步移除内置笔记、摘要、问答、Live Q&A 和行动项的全部操作入口及 AppState 调用链。此前仅隐藏主入口、把旧工作台收进折叠区，未满足精简范围；下文涉及可选折叠区的内容是历史记录。右侧现在只展示分组，设置只管理语音识别模型；原有历史数据继续兼容保存。

`zsh Scripts/test-library-management.zsh` 和 `python3 Scripts/test-recording-entry.py` 均通过，覆盖转录编辑、保存失败保护、分组、真实静音播放器、CLI/MCP、录音与退出状态、模型校验及历史内容保全。旧生成能力的独立工具类仍未做无关清理，但产品视图和 AppState 已没有通向这些能力的入口。

最新隔离预览构建与深度签名校验通过。原生逐项核对主界面、更多菜单、整理弹窗、导出页及设置四个页面，未发现旧工作台入口；同时确认外部 Agent 接入保留。验收预览补齐生产应用已有的 Settings 场景，避免设置按钮在测试壳中无法打开。真实资料经新 CLI 读取，正文、段落、音频引用、分组、转录 revision 和 contentDigest 与之前快照一致。本机证据为 `assistant-retired-validation.json` 和 `assistant-retired-*.ax.txt/png`，含私人内容，不提交仓库。本轮没有开启真实录音、重跑 ASR、改写个人库或发布安装包。

根据用户最新要求，时间点的页签、侧栏、段落菜单、表单、持久化模型、搜索和 Agent 返回字段均已移除。主阅读页直接显示正文；原文时间戳及逐段回听保留。旧开发字段兼容忽略，公开快照重发清理字段并通知 Agent 刷新。

本轮五组 Swift 回归、CLI/MCP 集成及九项报告契约通过。原生页面确认无时间点入口，现有分组与转录可用。实际前后快照的正文、段落、音频引用、contentDigest 和转录 revision 相同，旧书签备注不再参与搜索。详细源码与二进制摘要保存在本机 core-only-validation.json，截图为 recording-transcript-groups.png。以下包含时间点的日志均为历史记录，不代表当前范围。

受检分支：`codex/adaptive-reports`。生产源文件摘要见 `source-manifest.json`；这是本地开发验证，不是 GitHub 安装包或旧 UI 设计稿的完整发布验收。

`zsh Scripts/test-library-management.zsh` 运行旧资料兼容、公开快照、按段编辑与归属恢复、真实静音播放器及局部音轨定位、分组/标签/标记持久化、查询、写盘失败和 CLI/MCP 回归，并运行九项报告契约测试。日志见 `regression.log`。首次标记窗口的录音 ID 传递问题由原生点击验收发现并修复，草稿现在绑定录音 ID。

原生验收覆盖主资料库、分组标签管理、搜索与空筛选、批量整理、时间点表单、时间点列表、转录时间线、窄窗口整理入口及重启。越界输入会留在表单中，修正后不弹过期错误。摘要及历史内容默认折叠，主阅读导航不再显示笔记与助手。

私人音频、新旧转录、完整 UI 截图和真实识别证据保存在仓库外。没有修改手机或个人录音库，没有开启麦克风或发布音频。最终预览使用隔离临时目录；本机预览包复用已安装引擎，只用于本机验收，不能当作分发安装包。

未声称识别准确率提高、说话人数完全正确或所有原音逐字无漏识别。原始录制时间与导入时间分离仍为后续优化项。

最终本机预览以 APFS 克隆方式复制相同的已安装引擎文件，移除指向包外的开发符号链接；重新签名后通过 `codesign --verify --deep --strict`。这没有生成分发安装包，生产源码未变。

## 后续界面反馈：紧凑转写

基于用户截图，将时间、发言人及正文改为同一行，移除重复头像，减少段间距。长句仅在正文列换行；原有播放、编辑及发言人菜单保留。重复的时间线视图合并回转写，导航仅保留转写与时间点。已重新编译和验证本机预览签名，并以实际长音频核对短句、长句换行、时间戳播放和段落编辑入口。此轮仅调整视图，未重跑 ASR 或迁移数据；本节为追加验证，不改写此前的时间线验收记录。私人截图与本轮源码摘要保存在原本机验收目录的 compact-layout-validation.json 中。

## 后续范围变更：移除标签、保留分组

根据用户反馈，标签功能从界面、状态、内部数据模型、查询/筛选、批量操作和 Skill 安装说明中移除。旧开发快照重发时清除退休字段并发布 metadata 事件；旧命令参数报错，避免悄悄返回全部资料。分组、书签、正文、原段落 ID 保留。侧栏的分组控件压为一行，批量入口移入列表标题，底部操作合并一行。

新版脚本回归通过，覆盖旧字段兼容、分组批量整理/筛选、分组删除与回收站恢复、时间点与真实播放器、CLI/MCP 参数移除，以及九项报告契约。原生页面已核对分组管理器、标签入口消失、已有分组和两个书签保留，以及列表空间增加。此前包含标签的日志是历史证据；本轮记录另存在本机 groups-only-validation.json，不改写旧 PASS。
