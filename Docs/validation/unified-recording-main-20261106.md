# 统一录音、弱声音定稿及 Mac main 集成验收

- 基线：本地 main `67f8e5f`，远端 main `ee8c7e9`。
- 纳入原统一录音框架及 `ab140a4` 的本地弱声音改进；生产组合验证版本为 `934b4f9`，后续文档提交不修改生产源码。
- 保留外观选项、热词批量添加及确认规则、紧凑分组入口、录音语言选择、mini、音源切换和录音中浏览。

## 分段原件与同步

分段 AAC、清单及本地引用继续作为原件。停止录音后，自动同步路径在后台生成完整单声道 M4A，并验证帧数、采样率、编码、完整解码及 SHA256 后才上传。每次续录对应一份完整文件；章节引用去重到同一份原件，使用捕获上下文保留全局时间轴。

使用原有普通音频分块协议，接收端无需识别内部录音清单。写入采用临时文件和原子提交；损坏的派生缓存可重新生成，原件缺失或哈希异常会阻止上传。生成失败、取消、断网或切换账号不会删除原始分段，也不会记作同步成功。

Agent 与播放器共用受控路径解析，现有分段原音不再被错误报告为缺失。Agent 返回 JSON 原音清单时明确使用 `application/json`，转录段落和音频序号保持对应。

## 组合验证

最终运行共 57 个检查步骤，失败 0、未执行 0；包含编译和准备步骤，不等同于 57 个独立业务 Case。

- 外观持久化，中英文及保存语种；热词批量解析、去重、候选隔离、同步。
- 分组、星标、编辑、段落播放；mini、音源配置、录音时浏览。
- 普通音频及分段音频播放、波形、完整导出、恢复、恢复后续录、暂停与音源切换；现有录音的开头、中间、末尾播放及原件摘要。
- 全库默认同步、音频未生成转录时同步、离线队列、冲突选择、恢复同步、两个账号隔离；分段续录自动上传、上传回复丢失后重启续传、第二客户端完整下载及摘要匹配。
- 分段续录的章节去重、时间轴、分组和段落 ID 保留；损坏派生缓存重建；损坏原件拒绝；本地原始引用和文件保留。
- Agent CLI/MCP、分组查询及无主窗口冷启动。
- 匹配源码重新构建的实际模型运行时：普通话离线、音频格式、续录定稿、粤语实时字幕、英语定稿/发言人、分段转录及衰减至 5% 音量的合成语音识别。

另用现有 41 秒真人录音的副本执行 24 秒分段、3 秒重叠的定稿路径，得到非空中文转录；网络由沙箱禁用，未登录账号，输入摘要不变。该项证明实际路径可用，不作为准确率或弱声音场景的通用保证。

加速双音源测试写入并校验每路 12 小时音频，共 8640 个独立分片，在 6 小时位置重开写入，检查完整帧数、哈希、解码、边界跳转及内存增长。此为加速合成验证，不是 12 小时真实设备耐久测试。

本轮旧资料验证覆盖 5 条现有分段录音、7 份原音，使用外接盘副本；原始元数据和分段文件不做迁移、覆盖或删除。
