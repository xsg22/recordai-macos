# TalkTuck 0.17.3（2115）功能验证版

适用于 Apple Silicon Mac，系统要求 macOS 14 或更新版本。

- 录音时先显示实时字幕，再快速修正完整发言。长录音分批定稿，普通话每批 480 秒，英语每批 360 秒，停止后处理剩余尾段。
- 接缝对齐失败时，可以只重试出问题的接缝。后续批次继续处理，原音和已完成的定稿保留。
- 转录按句末标点、发言人和停顿分段。可以按段回听、校正文字、导出 Markdown 或原始 SRT，并通过 CLI 或 MCP 查询定稿。

本次在 Mac 上验收了 mini 悬浮窗录音、三阶段转录、长录音恢复、音频导入、双发言人分段、段落回放、校正、分组和 Agent 查询。英文和中英混合转录使用包内引擎实测。发布验收记录位于仓库的 `Docs/validation/release-2115`。

语音运行时与 Python 3.12 已内置，模型权重首次使用时按需下载。DMG 和 PKG 均附 SHA-256 文件。App 使用临时签名，PKG 为未签名安装包，Developer ID 签名和 Apple 公证留待正式版。
