# RecordAI 0.16.1 功能验证版

本版新增统一 Agent 接入：首次产生有效转录后提示一次，设置与交付页均可复制接入提示词。把提示词交给支持本机文件或命令访问的 Agent，由它获取当前版本 Skill、识别自己的环境并安装，无需在 App 内选择 Agent。

- CLI `setup --json` 与 MCP `get_agent_setup` 提供完整 Skill、实际安装和数据路径及验证步骤。路径随运行中的 App 动态生成。
- 可查询转录、发言人、音频引用及增量变更。录音控制支持明确请求后唤起 App，并分别查询命令回执和实际状态；接入安装不会自动开始录音。
- 修复引导跟随当前新转录记录的边界，并改善引导及无麦克风状态下的窗口布局。
- Python 3.12 和语音引擎内置；首次使用仍需在 App 下载并校验模型。无麦克风时可导入音频进行本地转录。

发布前对当前候选包复验合成双人中文音频的导入、转录、发言人分段、段落回放、人工校正和导出；22 组既有隔离回归及新增 CLI/MCP/Skill 集成验证通过。GitHub 构建再次执行自动回归和安装包内容校验。

真实 Codex、Claude Code、WorkBuddy、豆包等各产品的 Skill 加载兼容性尚未全部联测；云端环境可能无法访问本机。真实硬件录音与首次系统授权、外部 OAuth、远端文档写入不属于本次通过范围。合成样本不代表真实会议总体准确率。完整 45 页 UI 逐页视觉验收尚未完成，本版不宣称 100% 还原。

适用 Apple Silicon、macOS 14 或更新版本。DMG 和 PKG 任选其一，附 SHA-256 校验文件。应用使用 ad-hoc 签名，尚未经过 Apple 公证，macOS 可能要求手动批准打开。

升级保留本机会议、音频和模型；请勿删除资料目录。需要回退时可使用 Releases 保留的 0.16.0 功能验证版。若移动 App 安装位置，请重新复制接入提示词并更新 Skill 连接配置。
