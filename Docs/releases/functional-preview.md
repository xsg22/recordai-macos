# TalkTuck 功能验证版

适用于 Apple Silicon，要求 macOS 14 或更新版本。版本与 build 号以本次标签对应的 `Resources/Info.plist` 为准。

主要功能为本机录音、音频导入、转录、分组与 Agent 查询。CLI、Skill 与 MCP 统一为 `talktuck`；从 App 的“设置 → Agent 与数据”重新复制当前版本接入提示词。

模型按需下载并校验；语音运行时与 Python 3.12 已内置。现有录音目录与 Bundle ID 保持稳定。服务地址前缀迁移会保留当前账号的离线同步状态，冲突时暂停同步并保留两侧文件。

此文件是后续功能验证发布的说明模板。发布工作流必须先检查该标签绑定的原生主功能证据、回归与安装包；旧归档不能替代当前验收。功能验证版不代表全页面视觉验收通过。

安装包使用临时签名，尚无 Developer ID 签名与 Apple 公证。DMG、PKG 和各自 SHA-256 校验文件随发布提供。
