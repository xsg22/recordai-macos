# RecordAI 0.17.1 功能验证版

本版继续围绕本地录音、转录和分组，方便在录音时查看和整理内容。

- 录音过程中可分别开关麦克风和系统声音，两个音源均可关闭；切换只作用于当前录音。
- mini 悬浮窗提供录音控制和双行实时字幕。录音时可以浏览其他记录，并返回当前录音。
- 录音卡片支持分组、星标和导出等操作；列表点击范围和文字提示更加清晰。
- 保留中英文界面、音频导入、本地转录、原音回听以及 Agent 查询入口。

本机曾完成系统声音采集与实时转录测试；自动测试覆盖音源切换、录音期间浏览、分组、导出和 Agent 契约。不同麦克风、系统音频设备及会议软件组合尚未逐一实测。转录准确率取决于音源和模型，请结合原音核对。

适用于 Apple Silicon 和 macOS 14 或更新版本。首次使用需在应用内下载语音模型。应用为临时签名且尚未经过 Apple 公证；升级后若系统声音被拒绝，可能需要在系统设置中重新添加 RecordAI 的录屏与系统录音权限。升级不会主动删除已有录音和模型。

这是功能验证预发布，不代表完整页面视觉验收或 Windows 客户端已完成。DMG 和 PKG 任选其一，下载后可使用附带的 SHA-256 文件校验。
