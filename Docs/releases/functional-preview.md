# RecordAI 0.16.2 功能验证版

本版将桌面端收敛为录音资料库：录音或导入、转录、回听、校正和分组管理。分析总结交给外部 Agent 按需处理。

- 新增一层分组，支持创建、重命名、移除、筛选和批量移动。移动分组不复制音频，不改变转录引用；删除分组后录音回到未分组。
- 转录采用时间、发言人、正文同一行的紧凑布局，保留逐段回听、段尾自动暂停和人工校正。新转录合并连续短碎段；旧转录仅在阅读层整理，不自动重写个人库。
- 删除内置笔记、摘要、问答、Live Q&A 和行动项的全部操作入口；右侧只保留分组，设置只管理语音模型。标签和手动时间点暂不提供，旧版笔记等历史内容继续兼容保存。
- CLI/MCP 新增按标题、正文和分组查找；分组使用独立元数据版本，改分组不会使正文引用失效。统一 Skill 接入、状态查询和明确请求后的录音控制继续保留，接入安装不会自动录音。
- Python 3.12 和语音引擎内置；首次使用仍需在 App 下载并校验模型。无麦克风时可导入音频进行本地转录。

发布前验证当前候选包的合成双人中文音频导入、转录、发言人分段、段落回放、人工校正和导出，以及分组和已退休入口的实际页面。22 组既有隔离回归、CLI/MCP/Skill 集成、资料管理与碎段回归、9 项离线报告契约均执行；GitHub 构建再次执行自动回归和安装包内容校验。详情见 [本版验证记录](https://github.com/xsg22/recordai-macos/tree/main/Docs/validation/release-0.16.2)。

真实 Codex、Claude Code、WorkBuddy、豆包等各产品的 Skill 加载兼容性尚未全部联测；云端环境可能无法访问本机。真实硬件录音与首次系统授权、外部 OAuth、远端文档写入不属于本次通过范围。合成样本不代表真实会议总体准确率。完整 45 页 UI 逐页视觉验收尚未完成，本版不宣称 100% 还原。

适用 Apple Silicon、macOS 14 或更新版本。DMG 和 PKG 任选其一，附 SHA-256 校验文件。应用使用 ad-hoc 签名，尚未经过 Apple 公证，macOS 可能要求手动批准打开。

升级保留本机录音、音频和模型；请勿删除资料目录。需要回退时可使用 Releases 保留的 0.16.1 功能验证版。若移动 App 安装位置，请重新复制接入提示词并更新 Skill 连接配置；旧 Agent 可重新获取当前 Skill，以使用分组查询。
