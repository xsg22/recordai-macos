# TalkTuck 0.17.3（2120）功能验证版

适用于 Apple Silicon、macOS 14 及以上。提供 PKG 安装包和 SHA-256 校验文件。

- 主窗口右上角可打开 TalkTuck 账号设置；账号登录与第三方账号设置保持独立。
- 优化手机号、验证码、隐私政策链接和登录按钮的布局；账号设置页可用关闭按钮或 Esc 退出。
- 录音设置集中在一个入口，选择录音语言和音源更容易；录音后可返回新录音配置页。
- 增加意见反馈入口，并移除执行追踪界面。

已在真实 Mac 安装并打开 2120 版；账号入口和中英文登录页面使用隔离演示数据验证，表单启用条件与录音入口相关自动回归通过。本轮未使用真实手机号重新发送验证码，也未重新完成所有硬件与生产同步验收。语音模型首次使用时需单独下载。

App 使用临时签名，PKG 未签名，尚未经过 Apple 公证。升级前请先结束并保存录音；如系统声音录制被拒绝，请在系统设置中重新为应用授权。升级不会主动清理用户录音和模型。
