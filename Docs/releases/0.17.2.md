# TalkTuck 0.17.2（44）

适用于 Apple Silicon、macOS 14 或更新版本。

- 应用名称、侧栏及安装包统一使用 TalkTuck 与新的蓝色双波纹图标。
- TalkTuck 账号与钉钉、飞书、Notion 分开设置，登录入口指向自己的账号页。
- 提供个人热词确认、离线持久化和账号隔离；候选词只在本地提取，确认后用于最终转录。
- 保留录音 mini 悬浮窗、音源独立控制、分组、转录校正、原音回听与 Agent CLI/MCP。
- 集成主分支录音设备恢复和重复窗口修复，README 使用本版原生客户端效果图。

本版按主功能验证范围发布；完整设计册逐页验收尚未全部完成。本地流程、包内引擎、账号隔离及包内容验证范围见[验证记录](../validation/release-0.17.2/README.md)。真实手机双向同步和第三方真实授权不在本次发布验收范围。

应用使用本地 ad-hoc 签名，尚未 Apple 公证。Python 3.12 和语音引擎已包含在安装包内，用户无需单独安装 Python；首次使用仍需下载并校验模型权重。

提供 DMG、PKG 与对应 SHA-256 校验文件。原始录音与模型存储在应用包外，更新应用不会清理用户资料。
