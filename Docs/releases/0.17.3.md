# TalkTuck 0.17.3（55）

适用于 Apple Silicon、macOS 14 或更新版本。提供 DMG、PKG 及各自的 SHA-256 文件；Python 3.12 与语音运行时内置，模型仍在首次使用时按需下载。安装包采用本地签名，尚未 Apple 公证。

## 这次更新

- 录音界面直接选择普通话、粤语、英语和中英自动。粤语现在支持主窗口与 mini 悬浮窗实时字幕，停止保存后生成定稿。
- TalkTuck 账号登录后默认同步全部本机未归属其他账号的录音资料，包括转录定稿、分组和原音，无需逐条勾选。同步总开关可暂停传输，恢复后补齐离线修改；活动录音和临时字幕暂不上传。
- 个人热词支持批量添加，过滤明显普通词与句子碎片；只有已确认词用于识别和账号词库同步，减少实时校正时误插入热词。
- 修复后台冷启动后 Agent 列表为空：账号恢复与数据发布不再依赖主窗口出现，系统钥匙串暂不可用时重试。同步缓存损坏时仍可读取所属账号的本地转录；恢复账号期间保留有效快照，避免误报删除。
- 更新 README 实际界面图。CLI、Skill 与 MCP 名称统一为 `talktuck`；升级后从“设置 → Agent 与数据”重新复制接入提示词。

## 验证与边界

55 版已安装到真实 Mac。新进程隐藏启动且主窗口未打开时，CLI 与 MCP 的录音列表、详情和定稿查询通过；原有录音、原音摘要、段落 ID 和分组保留。钥匙串暂不可用、断网、账号切换及同步缓存损坏使用隔离夹具回归，没有额外重启整台 Mac。

粤语采集、实时字幕、暂停恢复、停止定稿、回听和重开后的持久化在同版本的 53 号构建实测，使用六段公开 FLEURS 真人粤语朗读音频。55 沿用同一语音引擎，包内引擎摘要一致；本轮未重新录制整套语料。小样本结果不代表所有口音、噪声或多人场景的准确率。

全部内容自动同步通过实际 Mac 适配器与隔离 HTTP/SQLite 后端测试，包含空分组、原音逐字节往返、暂停与恢复、离线状态和账号隔离。这些结果不等同于本轮已完成生产账号全量上传或最新 iPhone 真机双向验收。原音冲突需要用户明确选择版本，不静默覆盖。

本次仅发布 macOS 安装包，不包含 Windows 包。完整的历史全页面视觉验收不作为 55 版的新通过证据。

## 安装与恢复

安装前停止并保存正在进行的录音。升级保持原有资料目录；更换本地签名的应用后，如果 macOS 拒绝系统声音采集，请在“隐私与安全性 → 录屏与系统录音”中重新为“应用程序”内的 TalkTuck 授权。启动新录音后确认实际采集状态，权限开关本身不等于采集成功。

若需回退，先停止录音并备份资料，再安装已验证的旧包。回退应用不会撤回已经上传的数据；不要通过删除资料目录解决同步问题。
