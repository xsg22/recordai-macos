# RecordAI 产品亮点与使用场景

更新于 2026-11-03。用于后续 README、官网介绍和 PR 宣传选题；场景方向与已验收能力分别说明，避免将待验证的兼容性写成承诺。

## 线上会议：把双方的讨论留下来

**卖点文案：线上开会，专心交流；会后有原音，也有可检索的文字。**

用户在电脑上参加线上会议时，用 RecordAI 保存会议音频并转录，之后搜索关键内容、回听原话，或交给外部 Agent 提炼结论。目标场景包括腾讯会议网页版和桌面版。

- 双方都要记录时，选择「会议 · 麦克风和系统声音」：麦克风记录自己的发言，系统声音记录对方的发言。
- 只需记录对方时，可选择「系统声音」；戴耳机无需依赖扬声器外放拾音。
- 保留原音、转录、分组和按段回听，方便会后核对。

**当前证据边界：**macOS 客户端已有麦克风与系统声音双路采集实现；腾讯会议网页版、桌面版中的真实双向通话、同时使用麦克风及不同耳机组合，尚未专项验收。对外暂不使用「腾讯会议已验证」「绝不冲突」等表述。正式作为兼容性卖点发布前，应分别验证双方发言的原音回放与转录，以及暂停、恢复和设备切换。当前采集系统声音，不是只录指定会议应用，其他应用声音也可能被录入。

## 线下会议：没听懂的专业名词，会后再弄明白

**卖点文案：先把讨论记下来，没听懂的专业名词，会后结合上下文问 Agent。**

参加行业会议、技术交流或跨专业讨论时，用户可能因为不熟悉术语，来不及理解和记录。用 App 录下现场讨论，转成文字后，再把转录交给外部 Agent 查询术语含义、解释缩写，并结合当时的语境理解发言。

使用路径：录音 → 转录 → 搜索或定位不懂的词 → 回听核对原话 → 交给 Agent 解释。

可复制给 Agent 的示例提示词：

> 请读取这条录音的转录，找出其中的专业术语和缩写。逐项给出原文及时间位置、通俗解释，以及它在这段讨论中的含义。通用定义请提供可核实的来源；结合语境的推断请明确标注。疑似识别错误的词请列出候选，并提示我回听确认，不要把猜测当成事实。

**能力归属：**RecordAI 负责保存、转录、回听和向 Agent 提供文字；名词查询与解释由外部 Agent 完成。此场景不新增 App 内的会议助理、术语自动解释或实时问答功能。专业名词可能被转错，应结合原音核对；不宣传「术语识别零错误」或「自动解释所有术语」。

## 共同定位

**把声音保存好，把文字交给 Agent。**

线上会议侧重会后找回讨论，线下会议侧重会后理解陌生内容。两种场景都围绕录音、转录和分组展开，分析按需交给外部 Agent。
