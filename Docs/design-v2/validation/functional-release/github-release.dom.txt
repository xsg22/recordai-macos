  - heading "RecordAI 0.16.0 功能验证版" [level=1]
  - paragraph: 本次优先交付已验证的本地录音资料与音频导入流程。界面采用新版设计；44 页视觉验收仍在进行，未宣称 100% 还原。
  - list:
    - listitem: Python 3.12 和语音引擎随应用打包，最终用户无需安装 Python；语音模型在首次使用时下载并校验，之后可本地转录。
    - listitem: 没有麦克风也可导入音频，直接点击“开始转录”。可区分发言人、按段回放、人工校正，并导出 Markdown、TXT、JSON 和原始 SRT。
    - listitem: 已在真实候选客户端导入 31.296 秒的双人合成中文音频：首次 10.647 秒、主入口复验 8.528 秒完成，得到 4 段和 2 位发言人。
    - listitem: 分段回放、人工校正保留时间与发言人、Markdown / 原始 SRT 导出已实测；22 组隔离回归和安装包内容校验通过，GitHub 构建会重新执行这些自动检查。
  - paragraph: 识别样本中有一处“设计组”被识别为“测试组”，忽略标点的字符错误率为 1.77%。这是清晰合成样本，不代表真实会议总体准确率。真实麦克风采集、外部 OAuth 和远端文档写入未作为本次实测通过项；相关逻辑有隔离回归覆盖。
  - paragraph: 适用 Apple Silicon、macOS 14 或更新版本。下载 DMG 后把 RecordAI 拖入“应用程序”，或使用 PKG 安装。两个格式任选其一；SHA-256 校验文件一同提供。
  - paragraph: 应用使用 ad-hoc 签名，尚未经过 Apple 公证，macOS 可能要求手动批准打开。
  - paragraph: 升级保留本机已有会议、音频和模型。需要回退时，可安装 Releases 中保留的 0.15.1；请保留本机资料目录，不要为回退删除录音数据。
