## 契约与页面编排

`Reports/analysis-report.schema.json` 是完整数据契约，`Reports/report.py` 为单一契约定义与渲染实现。分析草稿只提供标题、概述、内容块、引用及覆盖声明；宿主追加录音 ID、revision、contentDigest、完整原文和生成来源。

支持 key_points、actions、decisions、questions、topics、concepts、timeline、quotes、narrative 和 comparison 内容块。分析者决定块的顺序和 primary/secondary 重点。版式按首个重点块确定，混合内容保留各自表现形式；课程中的附带待办不会自动把整页变成会议模板。不存在空的“决议”“行动项”占位区，也不允许模型注入任意 HTML/CSS/脚本。

本次产品周会没有方案对比和明确表决，选择行动简报：两项跟进事项、两条背景要点、一个待确认时间。11 月 6 日前保留月日口径，不补年份；未说明的测试期限使用 null。发言人误分保留为核对提示，不推断真实姓名或参会人数。

HTML 的文本都经过转义，数据与脚本分离，CSP 不允许对外连接。页面不加载远端字体、统计或 CDN。可附单个本地音频；点击引用会展开原文并定位，手动播放后在段尾暂停。相同秒数的多段引用合并显示，较多引用默认折叠，展开后全部可见；JSON 中仍保留全部来源编号。多音频部分的报告本轮只提供文本引用，不错误映射到第一段音频。

待办勾选属于浏览器本地操作状态，与正式分析 JSON 分开；存储不可用时明确提示只在本次打开期间有效。

## 可重复生成

需要 Python 3.12 或项目支持的 Python 环境，不额外依赖 Python 包。

```sh
# 通过安装的 Skill connection.json 获取 CLI，读取正式转录，不启动录音。
python3 Scripts/analysis-report.py prepare \
  --recording-id 0AF69966-9667-43D3-AE4D-6BEA884870AE \
  --out .build/report-input-new

# 分析者按 analysis-input.json 和 draft-schema.json 生成 analysis-draft.json。
# 本次草稿保存于 Docs/examples/adaptive-report/analysis-draft.json。
python3 Scripts/analysis-report.py render \
  --snapshot .build/report-input-new/snapshot.json \
  --analysis Docs/examples/adaptive-report/analysis-draft.json \
  --provider 'Codex（本次对话分析）' \
  --verify-current --include-audio \
  --out .build/report-output-new

python3 Scripts/analysis-report.py validate \
  .build/report-output-new/report.json \
  --snapshot .build/report-input-new/snapshot.json
```

`prepare` 按字符预算切分全部段落，超长单段保留精确字符范围。本轮不调用模型，也没有实现自动 map/reduce 模型调度；长文的实际分析与合并由分析者完成。字符分块不等同于模型 token 预算。

`render --verify-current` 再读取一次当前版本，拒绝旧版本或原文不一致的分析。完整覆盖必须包含全部 sourceIds；部分覆盖不能引用已声明遗漏的片段。直接引语须逐字存在于所引用的原文。校验可证明格式、引用存在及版本一致，不能自动证明每个结论在语义上忠实，分析者仍须核对。

输出目录含 report.json、report.html、schema.json、可选 audio.m4a 和宿主清单。先完整生成到临时目录再替换；仅 `--replace` 可更新未被修改的自有报告包，不覆盖用户额外文件或人工修改。示例音频仅存在本机，被仓库既有忽略规则排除。

JSON 文件已生成并校验，HTTP 请求实际返回 200；当前内置浏览器没有回传下载完成事件，不能宣称已验过其下载管理器。可直接打开本地 JSON 文件。打印入口已实现，本轮未验收系统打印对话框或 PDF 产物。
