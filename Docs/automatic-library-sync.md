# 全部内容自动同步

生效规则：2026-11-05 用户要求替代逐条选择的同步方式。

- 登录 TalkTuck 账号后默认开启同步，将未归属账号的本机录音、转录定稿、标题、发言人、星标、分组（含空分组）和原音归入当前账号。无须选择单条录音。没有转录或识别失败的录音仍同步元数据及可用原音。
- 活动录音和未收完的 Watch 音频延后处理；临时字幕、识别中的草稿不上传。已有定稿在续录时保留上次的定稿快照。新的定稿完成后增量同步。
- 服务端确认资料后自动排队原音上传。另一端拉取资料后自动下载原音；按账号持久化队列、校验摘要，重复扫描不重复上传。一个原音任务的冲突或失败不阻止其他就绪任务。
- 一个总开关控制文字、分组及原音的自动传输；明确暂停后不发起新传输，重启及同账号恢复继续保持暂停。恢复后自动补齐新增资料和离线修改。已发送的网络请求无法撤回，回调通过会话代次隔离。
- 切换账号后，不认领或上传其他账号资料。原有逐条选择状态仅升级一次到自动同步；升级后保留用户明确设置的暂停状态。
- 文字冲突保留双方，由用户选本机或云端版本。原音双方不同也必须明确选版本，不静默覆盖。
- 账号同步不代表授权云端 AI 处理或向第三方工作区分享；这些入口继续单独操作。

接口与数据库复用现有 userId 归属、版本和幂等机制，不新增正式服务端表或部署步骤。

验证采用实际 Mac/iPhone 适配器、回环 HTTP 服务与 SQLite、合成音频和测试账号；不得将隔离验收写成正式安装包或真机 iPhone 已验证。
