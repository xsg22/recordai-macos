# 个人热词同步

确认的热词保存在本机；登录现有 TalkTuck 账号后，客户端自动与该账号的 `/v2/hotwords` 同步。仅同步已确认的词，候选词、候选上下文、原始音频和转录正文不属于此接口。实时字幕不使用热词；Qwen 最终转录每段最多使用 12 个，优先选标题或前文出现的词，再补最近确认的词。

设备离线时保留本地修改并自动重试。服务端用版本号检测并发更新；客户端以最近一次共同版本比较增删，将本地增删应用到最新云端版本。两个设备同时添加不同词时保留两者；删除已有词时删除会保留。若不断出现新冲突，暂停本轮并在下次轮询重试；超过 1000 词时保留本地修改并提示整理。

本机未登录词库首次登录时只归属第一个账号；之后切换账号使用独立词库，不自动把前一账号或未登录词库复制给其他账号。退出后账号词库留在本机，重新登录同一账号可继续同步。

候选词提取使用 Qwen2.5-1.5B-Instruct 的 MLX 4-bit 模型（约 0.9 GB），在设置中下载后本机运行；模型文件按固定版本及 SHA-256 校验。候选聚焦人名、项目或产品名、公司机构、地名和专有术语，过滤明显的普通词及句子片段；既有待确认列表也按同一规则展示，已确认热词不受影响。提取可能遗漏或误判，只有用户确认后才进入词库，仍可手动批量添加。模型和转录数据不会发送至云端用于提取。

隔离测试：`TALKTUCK_TEST_NODE=/path/to/node python3 Scripts/test-hotword-sync.py`（通过 `TALKTUCK_SERVER_ROOT` 指定独立测试服务端目录）。测试使用内存数据库、合成账号、循环地址和内存凭据，不使用用户录音或真实账号。
