## 分组展示与任意卡片右键

创建分组只创建分类，不自动分配已有录音。现在管理分组时明确提示：创建后右键录音选择“移动到分组”，并展示每组的录音数量；已归组的卡片在日期和时长旁显示分组名。左侧分组筛选沿用现有筛选逻辑。

右键菜单绑定到整张录音卡片，包含星标、移动到分组（包括未分组与分组管理入口）、TXT/Markdown/JSON/原始 SRT/全部音频导出、移到回收站。没有字幕或音频的录音禁用相应导出项；采集、转录及保存期间沿用现有写入保护。回收站卡片提供恢复菜单。

分组、星标、导出与删除都显式绑定被右键的录音 ID，无需先选择；保存当前编辑后再处理目标，失效目标不回退为当前录音。删除确认显示目标标题，仅确认过的 ID 可以移入回收站；删除其他录音时当前页面保持不变。原音导出先在临时目录完成所有复制，再交付完整目录，失败时清理半成品并保留原音。
